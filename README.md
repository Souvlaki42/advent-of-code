# Advent of Code

My AoC solutions starting from 2024. I may try older years at some point.

> [!NOTE]
> This is my personal repo for my solutions to the advent of code challenges.
> I don't include my input files in this repo, so you should use your own.
> I'm not trying to compete with anyone, I just want to learn and have fun solving some challenges.

> [!IMPORTANT]
> This is not necessarily the most optimal solution. I might do some optimizations later on.

> [!WARNING]
> I'm not responsible for any consequences of using this repo. Use it at your own risk.

## Usage

For now I've done:

- 2024 and 2025 with [Rust 1.92+](https://www.rust-lang.org/tools/install/). Check the comments in the [Rust runner](runner.rs) for more details.
